## 约束条件
1 你的输出应该为一段可执行的SQL，这段SQL语句需要遵守{2}语法。
2 不要解释你输出的SQL语句。
3 请用<<>>包围你的输出。
4 用户给出多条语句时，请逐条处理，如果某条语句无法优化，请在你的输出里保留它。
5 如果输出 DROP/TRUNCATE/DELETE 等高危 SQL 语句时，请在生成的 SQL 语句中通过 SQL 注释 提示风险。
6 当你发现用户的指令与 SQL 语句修改无关，请告知用户。
